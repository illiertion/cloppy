Cloppy - Windows 클립보드 매니저
================================

앱 안의 사용법
  메인 창 왼쪽 "? 사용법" 또는 F1, 트레이 메뉴 → 사용법에서 같은 내용을 볼 수 있습니다.
  설정은 Ctrl+, 로 엽니다.

실행
  Cloppy.exe 를 더블클릭하세요.
  dist 폴더 전체가 필요합니다. exe만 따로 옮기면 실행되지 않습니다.
  (Cloppy-portable.zip 을 풀어서 실행해도 됩니다.)

언어
  기본 UI 언어는 English 입니다. 설정 → 모양 → 언어에서 English / 한국어를 고를 수 있고,
  저장하면 창과 메뉴에 바로 적용됩니다. (알림 문구도 함께 바뀝니다.)

설치 프로그램
  CloppySetup.exe 를 실행하면 시작 메뉴와 바탕화면 바로가기를 만들고 설치합니다.
  기본 설치 경로는 %USERPROFILE%\Cloppy 입니다.

주요 단축키
  Win+V            빠른 클립 창 열기/닫기 (Windows 기본 클립보드 대신 Cloppy가 열립니다)
  Ctrl+,           설정 창 열기
  F1               앱 내 사용법
  Ctrl+Alt+L       선택한 텍스트를 복사 없이 바로 한/영 교환 (기본값)
  Win+Alt+L        현재 클립보드 한/영 교환
  Ctrl+1 / 2 / 3   메인 창에서 클립 / 코드 블록 / 에셋 보기 전환
  Ctrl+N           새 폴더 (코드 보기에서는 새 코드 블록)
  Ctrl+Shift+N     어디서든 새 코드 블록
  Ctrl+F           검색
  Esc              팝업/설정/사용법 닫기

빠른 클립 창
  - 기본 크기는 398 × 500 이고, 오른쪽/아래/오른쪽 아래 모서리를 끌어 조절할 수 있습니다. 바꿈 크기는 다음에 열 때도 기억됩니다.
  - 위쪽 [클립] [코드] [에셋] 버튼으로 빠른 창에서 바로 전환합니다. 에셋은 클릭하면 경로가 복사됩니다.
  - 설정 → 빠른 창 폴더에서 고른 폴더가 빠른 창에 버튼으로 표시됩니다(여러 개 선택 가능).
  - 넓히고 설정에서 미리보기를 켜면 오른쪽에 미리보기가 함께 표시됩니다.
  - 목록을 한 번 클릭하면 이전 창에 바로 붙여넣습니다. Del 로 삭제, Ctrl+1~9 로 바로 붙여넣기.
  - 아래 [지우기] 버튼으로 고정하지 않은 클립을 한 번에 지울 수 있습니다.
  - 마우스 매크로(마우스 버튼에 Win+V 할당)로 열어도 Windows 기본 클립보드가 아닌 Cloppy가 열립니다.

클립 보기
  - 위쪽 탭 [클립보드] [코드 블록] [에셋] 을 눌러 보기를 바꿉니다 (Ctrl+1/2/3 도 동일).
  - 빠른 창에서도 [클립] [코드] [에셋] 버튼으로 같은 전환이 됩니다.
  - 텍스트, 링크, 이미지, 파일이 자동 저장됩니다. 한 번 클릭 = 선택, 더블클릭 = 복사.
  - 우클릭 → 변환하여 붙여넣기 (개발자 도구):
      JSON          압축 / 정리 / JSON 문자열
      HTML          줄바꿈 <br> 넣기 / 엔티티 변환 / 엔티티 해제
      문자열        이스케이프 / 이스케이프 해제 / 따옴표 문자열
      인코딩        URL encode / URL decode / Base64 / Base64 디코딩
      Markdown      코드블록 / 인라인 코드
      정리          한 줄로 / 쉼표로 연결 / 공백 정리
      이름 규칙     camelCase / PascalCase / snake_case / kebab-case / CONSTANT_CASE
      주석          각 줄 // 주석 / 각 줄 # 주석
  - "코드 블록으로 고정"을 눌러도 목록에서 사라지지 않고 📌 표시로 남습니다.
    고정한 항목은 자동 정리·"즐겨찾기 외 삭제"에서 삭제되지 않으며 코드 블록 보기에도 보입니다.
  - 전체 지우기 (고정 제외): 트레이 메뉴, 빠른 창 [지우기], 메인 창 [전체 지우기]에서
    고정한 항목만 남기고 모든 클립을 삭제합니다. (즐겨찾기도 함께 삭제됩니다.)
  - 목록 순서: 설정 → 동작의 "목록 순서 유지"를 켜면(기본값) 같은 내용을 다시 복사하거나
    붙여넣어도 목록 순서가 그대로 유지됩니다. 끄면 마지막 사용 순서로 정렬됩니다.

코드 블록 (Ctrl+2)
  - 코드 조각에 제목·언어·폴더를 지정해 보관합니다. 자동 정리에서 보호됩니다.
  - F2 또는 우클릭 → 코드 블록 편집으로 수정합니다.

에셋 (Ctrl+3)
  - 이미지, 폰트, 코드 파일을 앱 데이터 폴더로 복사해 보관합니다.
  - 에셋 전용 폴더/하위 폴더, 미리보기, 열기, 경로 복사, 폴더 이동, 삭제를 지원합니다.

텍스트 확장
  - 설정 → 텍스트 확장 단축어. 입력 후 Space/Tab/Enter 로 문구가 바뀝니다.
  - 기본 예: !mail → me@example.com. 추가·수정·삭제, 전체 사용 토글 가능.
  - 한글 단축어(!메일)도 되고, Cloppy 창 안에서도 동작합니다. 설정 창에서는 편집을 방해하지 않도록 동작하지 않습니다.

한/영 변환 방향 (설정 → 전역 단축키)
  자동     한글이면 영문 자판으로, 영문이면 한글로
  → 한글   dkssud → 안녕
  → 영문   안녕 → dkssud
  Ctrl+Alt+L 은 드래그한 선택 영역을 직접 바꿔 붙여넣고, 끝나면 이전 클립보드를 복원합니다.

개발자 모드 (설정 → 개발자)
  프로그래머 모드를 켜면 아래를 각각 켜고 끌 수 있습니다.
    · 터미널 복사 정리 (ANSI 색상·끝 줄바꿈/공백 제거)
    · 터미널에서 Ctrl+Shift+V / Ctrl+Shift+C 사용
    · 터미널에는 항상 서식 없이 붙여넣기
  터미널 앱 목록도 직접 편집할 수 있습니다.

폴더
  - + 또는 Ctrl+N 으로 만들고, 우클릭으로 하위 폴더·이름·색상·이동·삭제를 관리합니다.
  - 폴더를 삭제해도 항목은 지워지지 않고 폴더에서만 빠집니다.

라이선스
  Cloppy 와 Qt 는 GNU LGPL v3 조건으로 배포됩니다.
  트레이 메뉴 → 라이선스, 또는 설정 → 데이터 → 라이선스 보기에서 전문을 확인할 수 있습니다.
  배포 폴더의 LICENSE, LICENSES\LGPL-3.0.txt, LICENSES\GPL-3.0.txt, THIRD-PARTY-NOTICES.md 참고.
  Qt 는 DLL 로 동적 연결되어 있어 Qt 라이브러리를 교체·재연결할 수 있습니다.

문제 해결
  - Win+V 에 Windows 기본 클립보드가 열리면: 설정의 "Win+V 차단"을 켜고, 다른 클립보드 도구를 종료하세요.
  - 단축키가 안 되면: 설정의 "단축키 상태"를 확인하고, 다른 앱이 같은 조합을 쓰지 않는지 확인하세요.
  - 선택 변환이 안 되면: 텍스트를 실제로 드래그해 선택한 상태에서 누르세요.
  - 관리자 권한 앱에는 붙여넣기가 제한될 수 있습니다.

요구 사항
  Windows 10/11 64비트. 별도 설치 없이 실행됩니다.
