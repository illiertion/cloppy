Cloppy Help
Open settings
A Windows clipboard manager that collects everything you copy and organizes snippets and assets into folders.
Getting started
Press Win+V to open the quick window and Ctrl+, for settings. Everything you copy is recorded automatically; secret clips are kept separately in the lock at the top left.
Shortcuts
All global shortcuts can be changed or cleared in Settings, which also shows whether they are registered.

Quick window (Win+V)
The default size is 398 x 500 and you can resize it by dragging the right edge, bottom edge or corner; the size is remembered. Use the [Clips] [Snippets] [Assets] buttons at the top to switch views. Folders chosen in Settings appear as folder buttons, and clicking an asset copies its path.
Clip view
Switch views with the [Clips] [Snippets] [Assets] tabs at the top of the main window. A single click selects and shows a preview on the right; a double click copies it. In the Win+V popup a single click pastes into the previous window.
Right-click -> Paste as: JSON (compact/pretty), HTML (<br> line breaks), Markdown code block, single line, quoted string, Base64.
Right-click -> Move to folder to organize clips.
Pinning as a snippet keeps the item out of automatic cleanup and also stores it in the snippet view. Pinned items stay in the clip list.
Snippets (Ctrl+2)
Keep code snippets with a title and language in folders. They are managed separately from history and are never removed by auto-cleanup or Delete all but favorites.
Create one with + New snippet or Ctrl+Shift+N.
Press F2 or right-click -> Edit snippet to change its title, language or folder.
Pinning a normal clip also shows it in the snippet view.
Assets (Ctrl+3)
Copy images, fonts and code files into the app data folder. Organize them with asset folders and subfolders, and preview, open, copy paths or delete them.
Text expansion
Triggers added in Settings -> Text expansion are replaced after Space (or Tab/Enter), both in other apps and inside Cloppy windows. Default example: !mail -> me@example.com. Korean triggers (!메일) work too. Edit or remove entries, or turn the whole feature off.
Developer mode
Turn on programmer mode in Settings -> Developer and enable each behavior separately.
Clean terminal copies: strip ANSI color codes and trailing newlines/spaces.
Use Ctrl+Shift+V / Ctrl+Shift+C in terminals such as Windows Terminal, cmd and PowerShell.
Always paste into terminals without formatting.
The terminal app list can be edited.
Conversion direction
Choose the direction in Settings -> Global shortcuts. Auto converts Hangul to the English layout and vice versa; -> Hangul always converts one way (dkssud -> 안녕) and -> English the other (안녕 -> dkssud).
Folders
Create folders with + next to the folder header or Ctrl+N. Right-click a folder to create a subfolder, edit its name or color, move it, or delete it. Deleting a folder keeps its items and only removes them from the folder.
Folders chosen in Settings -> Quick window folders appear as buttons in the Win+V window so you can view just that folder. Choose several; none are shown by default.
Troubleshooting
If the Windows clipboard panel opens instead of Cloppy, close other clipboard tools and check that Block Win+V is enabled in Settings. Win+V sent from a mouse macro also opens Cloppy.
If a shortcut does not work, check Hotkey status in Settings and make sure no other app uses the same combination.
Pasting into apps running as administrator may be restricted.
If conversion does nothing, make sure text is actually selected (dragged). With no selection there is nothing to copy.
